# وثيقة التصميم الفني (Design Document) — المساعد الذكي التفاعلي لمنصة رواسي العمر

**تاريخ الوثيقة:** 2026-11-23  
**الموضوع:** نظام الرد والمساعد الذكي المدمج في الموقع مع ربط التحويل التنفيذي للواتساب  
**الحالة:** بانتظار المراجعة والاعتماد (Pending Approval)  
**الحجم المقدر:** مشروع ميزة متكاملة (Feature Project)  

---

## 1. الهدف والغرض (Intent & The Why)
طلبت إدارة شركة **رواسي العمر** تفعيل رد آلي ذكي للشركة، مع اعتماد توجّه أن يكون المحرك الأذكى مدمجاً وموجوداً مباشرة داخل البوابة الإلكترونية للمنصة، بحيث يقدم تجربة استشارية تفاعلية للعملاء والزوار على مدار 24 ساعة، ويجيب عن قطاعات الشركة وأدلة ونماذج مرجع الجمعيات، ويؤهل طلبات المشاريع ثم يُحيل العميل بملخص طلبه الموثق إلى واتساب الإدارة التنفيذية (`+966538881885`).

---

## 2. الأهداف والحدود (Goals, Non-Goals & Anti-Goals)

### الأهداف الأساسية (Goals):
1. **واجهة دردشة ذكية عائمة (Floating AI Assistant Widget):**
   - تصميم معماري أنيق ومتناسق بالكامل مع هوية رواسي العمر (`#163063` الكحلي، `#47A3B8` الفيروزي، `#F2F8FC`، خط `IBM Plex Sans Arabic`).
   - تطفو في الزاوية السفلية للموقع (RTL - أسفل اليسار أو اليمين المتسق مع تجربة المستخدم).
   - تقدم أزرار بدء سريعة (مثل: "استفسار عن تأهيل مقر"، "أدلة وتراخيص الجمعيات"، "طلب تسعير مقاولات وتوريد").
2. **محرك استشاري خبير ومؤصل (Grounded Domain Knowledge):**
   - مشبّع ببيانات الشركة الرسمية: القطاعات الخمسة (المقاولات، التوريد، التقنية، التشغيل، التنمية)، مسارات الجمعيات، ومنهجية المراحل الثلاث.
   - خبير في أدلة مرجع الجمعيات (الإجراءات، المتطلبات النظامية، والنماذج القابلة للتنزيل).
   - توجيه العميل بروابط مباشرة داخل المحادثة لتحميل النماذج أو الانتقال للقطاع المناسب.
3. **تأهيل وقيد طلبات المشاريع تلقائياً (Lead Qualification & CRM Ingestion):**
   - قدرة المساعد على استخلاص بيانات العميل ومشروعه (الاسم، الجوال، الجهة، نوع المشروع، القطاع، النطاق).
   - حفظ الطلب مباشرة في جدول `public.inquiries` بقاعدة بيانات Supabase، وإصدار رقم تتبع رسمي متسلسل (`RAO-2026-XXX`).
4. **تحويل ذكي للواتساب (Intelligent WhatsApp Handoff):**
   - زر تحويل فوري لواتساب الشركة التنفيذي (`+966538881885`) يحمل رسالة مهيأة مسبقاً تتضمن: الرقم المرجعي للطلب، ملخص الاحتياج، والبيانات الأولية، لتستلم الإدارة المحادثة دون أن يضطر العميل لإعادة الشرح.
5. **سرعة الاستجابة والاعتمادية:**
   - دعم تدفق الردود (Streaming Responses) أو الرد السريع عبر واجهة API خلفية محمية داخل Next.js.
   - وجود نمط احتياطي ذكي (Graceful Offline/Fallback Mode) يجيب بالمسارات الأساسية ويوجه للواتساب مباشرة في حال غياب مفتاح الربط أو انقطاع الاتصال.

### ما يقع خارج النطاق حالياً (Non-Goals):
- الربط البرمجي الكامل مع WhatsApp Cloud API عبر خوادم Webhooks من ميتا (مؤجل لمرحلة لاحقة بعد استيفاء توثيق الأعمال).
- الدفع الإلكتروني المباشر داخل المحادثة.

### محاذير يجب تجنبها (Anti-Goals):
- **تجنب الهلوسة والردود الإنشائية الركيكة (No Generic Slop):** ألا يقدم المساعد أي أسعار قطعية ملزمة دون دراسة هندسية، وألا يتحدث في مواضيع عامة خارج نطاق أعمال الشركة وخدماتها.
- **تجنب التصاميم المظلمة:** الالتزام الصارم بالهوية المعمارية المضيئة المعتمدة للشركة وعدم استخدام الثيمات الداكنة.
- **تجنب تسريب أي مفاتيح برمجية (API Keys):** مفتاح الذكاء الاصطناعي (`GEMINI_API_KEY`) وخلافه يعمل فقط على السيرفر (`Server-Side API Route`) ولا يمرر للمتصفح إطلاقاً.

## 3. الخيارات المقترحة والمسار المعتمد (Approaches & Decision)

| المسار | الوصف | الإيجابيات | التحديات | الحالة |
|---|---|---|---|---|
| **المسار 1: المساعد الذكي المدمج في الموقع + تحويل الواتساب** | بناء Native AI Widget في Next.js مدعوم بـ Gemini API ومرتبط بـ Supabase مع زر تحويل للواتساب بملخص الطلب. | تحكم كامل في الهوية، ربط مباشر بـ CRM الشركة، تكلفة تشغيل منخفضة، تجربة مستخدم سريعة وسلسة. | يتطلب إعداد مفتاح API في السيرفر. | **تم اختياره واعتماده من العميل** |
| **المسار 2: منظومة الذكاء الموحدة مع واتساب كلاود API** | بناء مساعد الموقع + روبوت واتساب رسمي عبر خوادم Meta Webhooks. | رد ذكي مباشر في واتساب والموقع بنفس اللحظة. | متطلبات توثيق مطولة من ميتا وتكاليف رسائل شهرية. | مؤجل لمرحلة توسعية |
| **المسار 3: تضمين أداة خارجية (SaaS Widget)** | اشتراك في منصة مثل Chatbase وتضمين سكربت جاهز. | إطلاق سريع بدون برمجة. | اشتراكات شهرية، صعوبة الربط مع Supabase CRM، ومظهر غير متناسق مع هوية الشركة. | مرفوض |

## 4. المكونات والمعمارية الفنية (Technical Architecture)

```
┌────────────────────────────────────────────────────────┐
│                   المتصفح (Client)                      │
│                                                        │
│  [AIAssistantWidget.tsx]                               │
│  - زر تفاعلي عائم + واجهة محادثة معمارية                 │
│  - أسئلة سريعة استرشادية                                │
│  - شارات تحميل النماذج وروابط الإجراءات                   │
│  - زر "المتابعة عبر واتساب بملخص الطلب"                  │
└───────────────────────────┬────────────────────────────┘
                            │ (POST /api/ai/assistant)
                            ▼
┌────────────────────────────────────────────────────────┐
│             Next.js 16 API Server                      │
│                                                        │
│  [/api/ai/assistant/route.ts]                          │
│  - فحص أمان الرسائل والتحقق من المدخلات                  │
│  - حقن السياق المعرفي (knowledgeBase.ts)                │
│  - التواصل مع Google Gemini API (gemini-2.5-flash)     │
│  - كشف نية العميل لطلب مشروع: استدعاء دالة قيد الطلب    │
└──────────────┬──────────────────────────┬──────────────┘
               │                          │
               ▼                          ▼
┌───────────────────────────┐  ┌─────────────────────────┐
│     Google Gemini API     │  │   Supabase Database     │
│ - توليد الردود الاستشارية   │  │ - حفظ الطلب في         │
│ - استخلاص بيانات العميل    │  │   public.inquiries      │
│ - صياغة ملخص الواتساب     │  │ - إصدار رقم RAO-2026-XXX│
└───────────────────────────┘  └─────────────────────────┘
```

### 1. الملفات والمكونات الجديدة:
1. **`src/components/public/AIAssistantWidget.tsx`**:
   - واجهة المستخدم التفاعلية (Floating Trigger Button + Drawer/Modal Window).
   - حالة المحادثة، مؤشر الكتابة التفاعلي، بطاقات النماذج القابلة للتحميل بنقرة واحدة، وزر التحويل إلى واتساب بالملخص.
2. **`src/lib/ai/knowledgeBase.ts`**:
   - مستودع المعرفة المدمج الذي يحوي:
     - نبذة ورسالة وميثاق رواسي العمر.
     - بيانات وتفاصيل القطاعات الخمسة (النطاق، المخرجات، المستفيدين).
     - إجراءات مرجع الجمعيات (المتطلبات، واللوائح، وروابط النماذج السحابية).
     - قواعد التعامل المهني والهندسي وسياسة الخصوصية.
3. **`src/app/api/ai/assistant/route.ts`**:
   - معالج الطلبات السحابي: يتلقى الرسائل، يدمج المعرفة، يتواصل مع Gemini، وفي حال توفر بيانات مشروع يقوم بإنشاء السجل في Supabase وإرجاع الرقم المرجعي ورابط الواتساب الجاهز.
4. **المتغير البيئي**:
   - إضافة `GEMINI_API_KEY` في `.env.local` و `.env.example`.

## 5. القرارات التقنية وقواعد التشغيل (Engineering Decisions & Builder Calls)

بناءً على المراجعة التقنية المعمارية للمشروع، تم اعتماد الضوابط التالية:
1. **مصدر المعرفة وتحديث البيانات (Knowledge Base Strategy):**
   - سيعتمد محرك المعرفة `knowledgeBase.ts` على ثوابت الموقع المعمارية وركائز الشركة الثلاث، مع ربط ذكي بقاعدة بيانات Supabase لجلب أحدث الأدلة المنشورة وروابط النماذج السحابية المعتمدة مع كاش زمني (`1 hour revalidation`) لضمان سرعة الاستجابة على خوادم Vercel Serverless.
   - روابط تنزيل النماذج التي يقترحها المساعد ستمر مباشرة عبر المسار المعتمد `/api/marjea/templates/download` لضمان احتساب وتحديث عدادات التنزيل في لوحة التحكم.
2. **تخزين المحادثة في لوحة الإدارة (CRM Transcripts & Notes):**
   - يتم تلخيص استشارة العميل واحتياجه الفني بصيغة Markdown منظمة وتُحفظ مباشرة في حقل `notes` بجدول `inquiries` الحالي، مما يتيح لمدير القطاع في لوحة التحكم (`/dashboard/leads`) رؤية الملخص فوراً دون الحاجة لتغيير هيكل الجداول.
   - محلياً لدى العميل، تُحفظ جلسة الدردشة في `sessionStorage` لتظل مفتوحة ومستمرة معه أثناء تنقله بين صفحات الموقع.
3. **حماية المورد وضبط الاستهلاك (Rate Limiting & Cost Control):**
   - حماية المسار بحد أقصى (15 تبادل رسائل لكل جلسة تصفح) لمنع استنزاف موارد الذكاء الاصطناعي أو هجمات السبام.
   - عند الوصول للحد الأقصى أو عند تعذر الاتصال، يُظهر المساعد رسالة اعتذار راقية وزراً مباشراً للمتابعة مع الفريق عبر واتساب.

## 6. ما يُترك لتقدير المطور (Left to the Builder)
- ضبط الحركة والظهور الفيزيائي للنافذة المنبثقة عبر `framer-motion` (Spring Transition).
- تحسين واجهة عرض الرسائل والأزرار السريعة لتلائم مقاسات الجوال (375px+) والشاشات العريضة.
- نصوص الأسئلة الترحيبية الاسترشادية حسب سياق الصفحة الحالية.
