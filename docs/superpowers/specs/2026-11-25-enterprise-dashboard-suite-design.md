# وثيقة التصميم الفني (Design Document) — منظومة لوحة الإدارة والحوكمة الشاملة (Enterprise Dashboard Suite)

**تاريخ الوثيقة:** 2026-11-25  
**المشروع:** منصة شركة رواسي العمر للاستشارات والتنفيذ المتكامل  
**الموضوع:** توسيع لوحة التحكم الداخلية (`/dashboard`) لتشمل: الموارد البشرية والحضور والانصراف، معرض المشاريع، المبادرات التنموية، والحوكمة المؤسسية وسجل الرقابة.  
**الحالة:** معتمد من الإدارة — جاهز لخطة التنفيذ (Approved for Planning)  
**الحجم المقدر:** مشروع متكامل عالي القيمة (Full Enterprise Suite)  

---

## 1. الهدف والغرض (Intent & The Why)
توسيع البوابة الإدارية لشركة **رواسي العمر** من مجرد لوحة متابعة طلبات (CRM) وإدارة أدلة (CMS) إلى **منظومة حوكمة وتشغيل مؤسسي متكاملة (Enterprise Operations & Governance Suite)**؛ تمكّن الإدارة التنفيذية من:
1. إدارة الكوادر البشرية، إضافة الموظفين، وأتمتة سجلات الحضور والانصراف والإجازات.
2. إدارة وعرض محفظة مشاريع تسليم المفتاح (معرض المشاريع المنفذة وقبل/بعد).
3. تتبع المبادرات المجتمعية ومؤشرات قياس الأثر التنموي (SROI).
4. فرض الحوكمة المؤسسية الصارمة وسجل الرقابة والتدقيق اللحظي (Audit Trail).

---

## 2. الأهداف والحدود (Goals, Non-Goals & Anti-Goals)

### الأهداف الأساسية (Goals):
1. **مركز الموارد البشرية والحضور والانصراف (`/dashboard/hr`):**
   - **إضافة موظف جديد:** إدخال البيانات الشخصية والوظيفية (الاسم، البريد، الجوال، القسم، المسمى، الدور، الراتب الأساسي، وتاريخ المباشرة) مع إنشاء حسابه تلقائياً في Supabase Auth وتعيين الصلاحيات.
   - **سجل الحضور والانصراف:** إمكانية تسجيل الحضور والانصراف اليومي، حساب ساعات العمل الفعلية، رصد حالات التأخير أو الاستئذان، وفلترة السجلات حسب التاريخ أو الموظف أو القسم.
   - **إدارة الإجازات:** تقديم واعتماد طلبات الإجازات (اعتيادية، مرضية، طارئة) مع دورة موافقة إدارية.
2. **معرض المشاريع والمحفظة التنفيذية (`/dashboard/projects`):**
   - إضافة وإدارة مشاريع تسليم المفتاح المنفذة وقيد التنفيذ.
   - الحقول: العنوان، القطاع التنفيذي، الجهة المستفيدة، المدينة، القيمة التعاقدية، نطاق العمل، صور قبل/بعد (Before & After)، وحالة العرض بالبوابة العامة.
   - خيار النشر الفوري في البوابة العامة (`/impact` و `/sectors`).
3. **مختبر المبادرات والأثر المجتمعي (`/dashboard/initiatives`):**
   - إدارة البرامج التنموية والشراكات مع الجمعيات والأوقاف.
   - تتبع نسب الإنجاز الميداني (Progress %)، المحطات الزمنية (Milestones)، ومؤشر العائد الاجتماعي على الاستثمار (SROI).
4. **مركز الحوكمة وسجل الرقابة الشامل (`/dashboard/governance`):**
   - استعراض سجل الرقابة والتدقيق الكامل (`audit_logs`) لكافة العمليات الحساسة (إنشاء موظف، تعديل أسعار، تغيير حالات الطلبات، اعتماد الأدلة).
   - مصفوفة الصلاحيات (RBAC Matrix) وإقرارات الامتثال واللوائح الداخلية.

### ما يقع خارج النطاق حالياً (Non-Goals):
- الربط بأجهزة البصمة البيومترية الميدانية في مواقع الإنشاء (الاعتماد على التسجيل السحابي الذكي).
- مسير الرواتب البنكي الآلي (WPS / SARIE)؛ يُكتفى حالياً بإدارة السجلات والاستحقاقات.

### محاذير يجب تجنبها (Anti-Goals):
- **تجنب التعقيد والبطء:** الحفاظ على سرعة التصفح والاستجابة الفورية دون شاشات انتظار ثقيلة.
- **الالتزام بالهوية البصرية المعمارية:** الالتزام الصارم بالألوان الرسمية المعتمدة (`#163063` الكحلي، `#2360A5` الأزرق، `#47A3B8` الفيروزي، على خلفيات `#FFFFFF` و `#F2F8FC` وبخط `IBM Plex Sans Arabic`).

## 3. المعمارية الفنية وهيكلية البيانات (Technical & Data Architecture)

```
لوحة الإدارة (src/app/(portal)/dashboard)
├── layout.tsx (القائمة الجانبية المحدثة بـ 7 أقسام)
│
├── /page.tsx (نظرة عامة ومؤشرات أداء مجمعة لجميع الأقسام)
├── /leads (إدارة واستقبال طلبات المشاريع CRM)
├── /marjea-cms (حوكمة نشر أدلة مرجع الجمعيات Maker-Checker)
│
├── /hr (الموارد البشرية وشؤون الموظفين) 🌟
│   ├── page.tsx (بطاقات الكادر + جدول الحضور والانصراف + طلبات الإجازات)
│   └── components/ (AddEmployeeModal, AttendanceTable, LeaveRequestModal)
│
├── /projects (معرض المشاريع والمحفظة) 🌟
│   ├── page.tsx (شبكة المشاريع + فلترة القطاعات + إحصاءات الإنجاز)
│   └── components/ (ProjectFormModal, BeforeAfterViewer, ProjectStatusBadge)
│
├── /initiatives (المبادرات التنموية ومختبر الأثر) 🌟
│   ├── page.tsx (متابعة المبادرات، مراحل الإنجاز، ومؤشر SROI)
│   └── components/ (InitiativeCard, MilestoneTimeline)
│
└── /governance (مركز الحوكمة وسجل الرقابة) 🌟
    ├── page.tsx (سجل التدقيق Audit Trail + مصفوفة الصلاحيات + الامتثال)
    └── components/ (AuditLogsTable, PermissionsMatrix)
```

### جداول البيانات ونموذج الحفظ (Dual-Layer Persistence):
1. **جدول `public.staff_attendance`**:
   - `id`, `staff_id`, `date`, `check_in_time`, `check_out_time`, `total_hours`, `status` ('present' | 'late' | 'absent' | 'excused'), `notes`.
2. **جدول `public.staff_leaves`**:
   - `id`, `staff_id`, `leave_type`, `start_date`, `end_date`, `days_count`, `reason`, `status` ('pending' | 'approved' | 'rejected'), `approved_by`.
3. **جدول `public.portfolio_projects`**:
   - `id`, `title`, `sector_slug`, `client_name`, `city`, `budget_range`, `summary`, `scope`, `before_image_url`, `after_image_url`, `status` ('completed' | 'in_progress'), `is_published`.
4. **جدول `public.initiatives`**:
   - `id`, `title`, `partner_name`, `sector`, `target_beneficiaries`, `achieved_beneficiaries`, `progress_pct`, `sroi_score`, `status`, `start_date`, `end_date`.
5. **جدول `public.audit_logs` (مفعّل ومربوط)**:
   - `id`, `actor_name`, `actor_role`, `action_type`, `entity_type`, `entity_id`, `details`, `created_at`.

## 4. مراحل التنفيذ المعتمدة (Implementation Phases)

* **المرحلة 1: الموارد البشرية ومعرض المشاريع (الأساس التشغيلي المباشر):**
  1. تحديث القائمة الجانبية وإضافة التبويبات الجديدة.
  2. واجهة الموارد البشرية `/dashboard/hr` (إضافة موظف، سجل الحضور، والإجازات) مع واجهات API مخصصة (`/api/hr/attendance`, `/api/hr/leaves`).
  3. واجهة معرض المشاريع `/dashboard/projects` مع واجهة API (`/api/projects`).
* **المرحلة 2: المبادرات التنموية والحوكمة الشاملة:**
  4. واجهة المبادرات والأثر `/dashboard/initiatives` مع واجهة API (`/api/initiatives`).
  5. واجهة مركز الحوكمة وسجل الرقابة `/dashboard/governance` مع واجهة API (`/api/governance/audit`).
  6. فحص شامل للبناء والتحقق النهائي وتحديث وثيقة التسليم [HANDOFF.md].
